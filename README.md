# 🍼 BabyCare – Modern Baby & Maternity E-Commerce Website

**BabyCare** is a modern, responsive, front-end e-commerce web application specializing in gentle baby care essentials, certified organic clothing, pediatric-approved feeding gear, nursery furniture, and maternity wellness.

Built entirely with standard **HTML5**, **Vanilla CSS3**, and **Vanilla JavaScript**, the application delivers a commercial-grade shopping experience with zero database or paid API requirements. All carts, wishlists, simulated user logins, baby registry lists, and order histories are seamlessly preserved in the browser's `localStorage`.

## 🌟 Key Highlights & Features

### 1. 🎨 Warm, Trustworthy & Pediatric-Grade Branding
- **Color Palette**:
  - Soft Pink (`#E85D7A`) – Nurturing warmth
  - Light Blue (`#7EC8E3`) – Gentle baby comfort
  - Cream White (`#FFFFFF`) – Pure and hygienic
  - Soft Blush Background (`#FFF8F8`) – Delicate visual warmth
  - Dark Charcoal (`#333333`) – High readability
- **Official Brand Logo**: Custom BabyCare vector and high-res brand artwork loaded directly from `BabyCare_logo_design_concept_20261019115541.jpg` with responsive crisp cropping and cute baby badge `favicon.png`.
- **Modern Typography**: Google Fonts – *Outfit* (bold display headings) & *Plus Jakarta Sans* (interface controls and body typography).
- **Aesthetic Elements**: Rounded cards (18–24px border radius), soft pill badges, micro-animations, glassmorphic headers, and folder-source tags on every product card.

### 2. 🔍 Instant Search, Multi-Filter & Workspace Directory Tabs
- **Folder Directory Tabs**: Filter by collection folder with 1 click:
  - *All Products (26)*
  - *Baby Clothing (6)*
  - *Diapers & Wipes (6)*
  - *Feeding & Nursing (6)*
  - *Nursery & Maternity (5)*
  - *Studio Signature (5)*
- **Instant Search**: Search across product names, categories, brands, and directory sources with real-time suggestion dropdown.
- **Category Filter Pills**: Fast 1-click filtering by category (*Diapers*, *Feeding*, *Clothing*, *Nursery*, *Toys*, *Maternity*).
- **Price Range Slider**: Filter products by maximum budget up to ₹25,000.
- **Age-Stage Explorer**: Personalized filter for Newborns (0-3M), Infants (3-6M), Crawlers (6-12M), Toddlers (1-3Y), and Expecting Moms.
- **Sorting Options**: Featured, Price: Low to High, Price: High to Low, Highest Customer Rating, and Most Popular.

### 3. 🛒 Interactive Shopping Cart with Free-Shipping Meter
- **Slide-Over Drawer**: Smooth sliding drawer accessible from any page.
- **Quantity Controls**: Increment, decrement (strictly prevented from dropping below 1), and remove items.
- **Dynamic Free Shipping Meter**: Real-time progress bar unlocking **FREE Express Shipping** on orders over ₹999.
- **Working Coupon Engine**:
  - `BABYCARE10` – 10% discount on order total
  - `FIRSTBABY` or `WELCOME200` – Flat ₹200 savings for new parents
- **Live Header Badges**: Cart count updates dynamically across all user interactions.

### 4. 💖 Wishlist & Baby Registry
- **Clean 0-Product Default**: By default, the store initializes with 0 products in the Shopping Cart, Wishlist, and Baby Registry.
- **Wishlist Management**: Save items by toggling heart icons; move wishlisted items directly into the cart with 1 click.
- **Baby Shower Registry**: Add desired nursery and baby essentials to a personal registry with progress tracker and shareable link generator (`#registry`).
- **LocalStorage Persistence**: As items are added or removed, they automatically synchronize and persist seamlessly across browser reloads.

### 5. 💳 Multi-Step Checkout Simulation (Demo Mode)
- **Step 1: Shipping Details**: Full Name, Email, Phone, Street Address, City, State dropdown, and 6-digit Indian PIN code validation.
- **Delivery Options**: Standard Delivery (Free above ₹999 / ₹99) or Express Priority Next-Day Air (₹149).
- **Step 2: Simulated Payment Methods**:
  - *Cash on Delivery (COD)* with zero surcharge
  - *Simulated UPI*: Instant GPay / PhonePe / Paytm QR display and VPA field
  - *Simulated Card*: Sandbox demo card inputs with clear security disclaimer
- **Order Confirmation & Tracking**:
  - Generates a unique simulated order number (e.g., `#BC-92841`).
  - Calculates estimated delivery dates.
  - Automatically saves the order to your local **Order History**.
  - **Live Order Tracker**: Visual milestone stepper (Order Placed ➔ Packed ➔ In Transit ➔ Delivered).

### 6. 📱 100% Responsive Design
- Optimized for desktop monitors, laptops, iPad/tablets, and mobile phones.
- Mobile slide navigation drawer with search and quick category access.
- Touch-friendly 44px+ hit targets for easy tapping.

## 🚀 How to Run Locally

You can run BabyCare immediately using any of the following methods:

### Option 1: Direct File Open (Easiest)
1. Navigate to the project directory: `d:\COURSES\tasks\BabyCare\`
2. Double-click `index.html` to open it directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Option 2: Using Python Built-in HTTP Server
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080/index.html` in your web browser.

### Option 3: Using VS Code Live Server
1. Open the `BabyCare` folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **"Open with Live Server"**.

## 🌐 Deployment Instructions

### Deploy to GitHub Pages (Free)
1. Initialize Git and commit the files:
   ```bash
   git init
   git add .
   git commit -m "Complete BabyCare e-commerce website with 26 products"
   ```
2. Create a new repository on GitHub and push the code:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/babycare.git
   git push -u origin main
   ```
3. In GitHub Repository **Settings > Pages**, choose the `main` branch and `/` root directory, then click **Save**.

### Deploy to Netlify (Free & 1-Click)
1. Go to [Netlify.com](https://www.netlify.com/) and sign in.
2. Drag and drop the `BabyCare` folder directly onto the Netlify dashboard.
