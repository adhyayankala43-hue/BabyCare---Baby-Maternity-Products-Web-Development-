# 🍼 BabyCare – Modern Baby & Maternity E-Commerce Website

**BabyCare** is a modern, responsive, front-end e-commerce web application specializing in gentle baby care essentials, certified organic clothing, pediatric-approved feeding gear, nursery furniture, and maternity wellness.

Built with standard **HTML5**, **Vanilla CSS3**, and **Vanilla JavaScript**, the application delivers a commercial-grade shopping experience with zero database or paid backend requirements. All shopping carts, wishlists, simulated user logins, baby registry lists, and order histories are seamlessly preserved in the browser's `localStorage`.

## 🌟 Key Highlights & Features

### 1. 🎨 Warm, Trustworthy & Pediatric-Grade Branding
- **Color Palette**:
  - Soft Pink (`#E85D7A`) – Nurturing warmth
  - Light Blue (`#7EC8E3`) – Gentle baby comfort
  - Cream White (`#FFFFFF`) – Pure and hygienic
  - Soft Blush Background (`#FFF8F8`) – Delicate visual warmth
  - Charcoal (`#333333`) – High readability
- **Brand Identity**: Custom vector logo and high-res brand artwork loaded directly from `BabyCare_logo_design_concept_20261019115541.jpg` with responsive crisp cropping and `favicon.png`.
- **Modern Typography**: Google Fonts – *Outfit* (headings) & *Plus Jakarta Sans* (controls & body text).
- **Aesthetic Elements**: Soft rounded cards (18–24px radius), smooth pill badges, micro-animations, glassmorphic floating headers, and clean metadata displays.

### 2. 🔍 Instant Search & Multi-Filter Catalog
- **Category Filter Pills**: Fast 1-click filtering by category (*All Categories*, *Diapers & Wipes*, *Feeding & Nursing*, *Baby Clothing*, *Nursery*, *Toys & Books*, *Maternity*).
- **Instant Search**: Search across product names, categories, and brands with real-time suggestion dropdown.
- **Price Range Slider**: Interactive budget filter supporting prices up to ₹25,000.
- **Age-Stage Explorer**: Filter by milestone (0-3M, 3-6M, 6-12M, 1-3Y, and Expecting Moms).
- **Sorting Options**: Featured, Price: Low to High, Price: High to Low, Highest Customer Rating, and Most Popular.

### 3. 🛒 Interactive Cart & Free Shipping Meter
- **Slide-Over Drawer**: Smooth sliding drawer accessible from any section.
- **Quantity Controls**: Increment, decrement (locked to minimum 1), and remove items.
- **Dynamic Free Shipping Meter**: Real-time progress bar unlocking **FREE Express Delivery** on orders over ₹999.
- **Working Coupon Engine**:
  - `BABYCARE10` – 10% discount on order total
  - `FIRSTBABY` or `WELCOME200` – Flat ₹200 savings for new parents
- **Live Cart Badge**: Real-time item counter updates across all header and mobile navigation bars.

### 4. 💖 Wishlist & Baby Registry
- **Clean 0-Product Default**: Initializes with 0 products in Cart, Wishlist, and Registry for authentic user experience.
- **Wishlist Management**: Save items with heart icon; move wishlisted items directly to cart.
- **Baby Shower Registry**: Add desired essentials to personal registry with progress tracker and shareable link generator (`#registry`).
- **LocalStorage Persistence**: Synchronizes cart, wishlist, and registry across browser sessions without a backend database.

### 5. 💳 Multi-Step Checkout Simulation (Demo Mode)
- **Step 1: Shipping Details**: Full Name, Email, Phone, Address, City, State, and 6-digit PIN code validation.
- **Delivery Options**: Standard Delivery (Free above ₹999 / ₹99) or Express Priority Next-Day Air (₹149).
- **Step 2: Payment Simulation**:
  - Cash on Delivery (COD)
  - Simulated UPI (QR display and VPA field)
  - Simulated Card (sandbox demo card inputs)
- **Order Confirmation & Tracking**:
  - Generates unique order number (e.g., `#BC-92841`).
  - Estimates delivery dates and saves order into local **Order History**.
  - Visual milestone stepper: Order Placed ➔ Packed ➔ In Transit ➔ Delivered.

### 6. 📱 100% Mobile & Tablet Responsive
- Fully responsive across desktop, tablet, and mobile displays.
- Slide-out mobile menu drawer with touch-friendly 44px+ hit targets.

## 🛠️ Installation & Local Setup Guide

Follow these steps to set up and run BabyCare locally on your machine.

### Prerequisites

Ensure you have either **Node.js** (recommended for package management and local serving) or **Python** installed:
- [Node.js](https://nodejs.org/) (v16.0 or higher)
- [Git](https://git-scm.com/) (optional, for version control)

### Step 1: Clone or Download the Project

```bash
# Clone the repository
git clone https://github.com/<YOUR_USERNAME>/babycare.git

# Navigate into the project folder
cd BabyCare
```

*(Alternatively, download the ZIP archive from GitHub and extract it to your preferred directory).*

### Step 2: Install Local Development Dependencies (Optional)

BabyCare includes a lightweight local server via `serve`:

```bash
npm install
```

### Step 3: Run the Local Server

Choose any of the following options:

#### Option A: Using npm script (Recommended)
```bash
npm run dev
# or
npm start
```
The application will be served at `http://localhost:3000`.

#### Option B: Using Vercel CLI locally
If you have Vercel CLI installed:
```bash
npx vercel dev
```
Runs the exact Vercel local emulation environment at `http://localhost:3000`.

#### Option C: Using Python Built-in Server
If you prefer not to use Node.js:
```bash
# Python 3
python -m http.server 3000
```
Open `http://localhost:3000/index.html` in your web browser.

#### Option D: Direct Browser Open or VS Code Live Server
- **Direct**: Double-click `index.html` to open directly in Google Chrome, Microsoft Edge, Firefox, or Safari.
- **VS Code**: Right-click `index.html` and select **"Open with Live Server"**.

## 🚀 Deployment Guide: Deploy to Vercel

[Vercel](https://vercel.com/) provides high-performance global CDN edge hosting with automated SSL, instant preview deployments, and zero backend maintenance.

### Method 1: Deploy with Vercel CLI (Fastest & Direct)

Deploy directly from your terminal in under 60 seconds:

1. **Install Vercel CLI globally** (or run with `npx`):
   ```bash
   npm install -g vercel
   ```

2. **Login to your Vercel account**:
   ```bash
   vercel login
   ```

3. **Deploy Preview**:
   Run the deploy command from the project root directory:
   ```bash
   vercel
   ```
   Follow the interactive prompts:
   - *Set up and deploy?* &rarr; **`Y`**
   - *Which scope?* &rarr; *(Select your Vercel account/team)*
   - *Link to existing project?* &rarr; **`N`**
   - *What's your project's name?* &rarr; **`babycare`** (or press Enter)
   - *In which directory is your code located?* &rarr; **`./`**
   - *Want to modify settings?* &rarr; **`N`**

4. **Deploy to Production**:
   ```bash
   vercel --prod
   ```
   *(Or run `npm run deploy` if dependencies are installed).*

   Your production site will be live at: `https://babycare.vercel.app` (or your assigned Vercel URL).

---

### Method 2: Deploy with Git & Vercel Dashboard (Continuous Deployment)

This method connects your GitHub repository to Vercel so that every `git push` automatically builds and deploys your updates.

#### 1. Push Code to GitHub
```bash
# Initialize git if not already initialized
git init

# Add all project files
git add .

# Commit changes
git commit -m "Complete BabyCare e-commerce website"

# Rename branch to main
git branch -M main

# Link remote GitHub repository
git remote add origin https://github.com/<YOUR_USERNAME>/babycare.git

# Push to GitHub
git push -u origin main
```

#### 2. Import into Vercel Dashboard
1. Go to [vercel.com](https://vercel.com/) and sign in with GitHub.
2. Click the **"Add New..."** button and select **"Project"**.
3. Under **Import Git Repository**, locate your `babycare` repository and click **Import**.
4. In the **Configure Project** screen:
   - **Project Name**: `babycare`
   - **Framework Preset**: **Other** (Static HTML)
   - **Root Directory**: `./` (Default root)
   - **Build and Output Settings**: Leave empty / default (Vercel automatically serves static assets).
5. Click **Deploy**.
6. Within seconds, Vercel will build and assign a production URL (e.g. `https://babycare.vercel.app`).

---

### Method 3: Deploy via Vercel Drag & Drop (No Git Required)

1. Open your browser and go to [vercel.com/new](https://vercel.com/new).
2. Drag and drop the `BabyCare` folder directly onto the Vercel dashboard upload zone.
3. Vercel will instantly upload all files and generate a live URL.

### ⚙️ Vercel Configuration (`vercel.json`)

BabyCare includes a pre-configured `vercel.json` file in the root directory for optimized static routing:

```json
{
  "version": 2,
  "cleanUrls": true,
  "routes": [
    {
      "handle": "filesystem"
    },
    {
      "src": "/(.*)",
      "dest": "/index.html"
    }
  ]
}
```

- **`cleanUrls: true`**: Removes `.html` extensions from URLs for cleaner routing.
- **`filesystem` handle**: Serves all images, CSS stylesheets, and JavaScript files directly with optimal MIME types and caching headers.
- **SPA Fallback**: Directs any subpaths cleanly back to `index.html`.

## ❓ Troubleshooting & FAQs

### 1. Product Images Not Showing on Vercel
- **Cause**: Case sensitivity on Linux servers or special characters in filenames (e.g., spaces and `&`).
- **Solution**: The application uses `encodeURI(product.image)` for all dynamic asset rendering, ensuring full compatibility across all operating systems and Vercel's global CDN.

### 2. Port Already in Use (Local)
- If port `3000` is already in use, specify a different port:
  ```bash
  npx serve -l 8080 .
  # or with Python
  python -m http.server 8080
  ```

### 3. Clearing Stored Cart & Registry Data
- BabyCare stores session state in your browser's `localStorage`. To reset to clean defaults:
  - Open Developer Tools (`F12`), navigate to **Application > Local Storage**, and click **Clear All**, or run in the Console:
    ```javascript
    localStorage.clear(); location.reload();
    ```
